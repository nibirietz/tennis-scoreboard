# tennis-scoreboard
Веб приложение для подсчёта очков теннисных матчей, с сохранением в базу данных.
## Технологии
- Python (3.14)
- Jinja2 (3.1.6) - шаблонизатор HTML
- PostgreSQL (18) - СУБД
- SQLAlchemy (2.1.8) - ORM
- Waitress (3.0.2) - WSGI-сервер
## Возможности
На главной странице(`/`) есть кнопки для создания нового матча(`/new-match`), либо переход на страницу с оконченными матчами. В `/new-match` дана форма для заполнения ников двух игроков, если игрока нет в базе данных, то создаётся запись в БД. Ники игроков должны быть уникальны, игрок не может играть сам с собой. После создания матча открывается `/match?uuid=$uuid`, где можно добавить очки участникам. \
На странице матчей(`/matches`) показывают завершённые матчи и победителей. Есть фильтр по игроку.
## Подсчёт очков
Подсчёт очков идёт по стандартным правилам, но есть упрощения:
- матч играется до двух сетов;
- тай-брейк идёт до 7 очков.
